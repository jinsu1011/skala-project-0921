# 설계 단계 기록 (보관)

설계서 개정 과정(v1.0 → v1.4)의 원문과 개정 비교, 개발 착수 때 쓴 작업 지시서를 보관한다. 현재 기준 문서는 `docs/DESIGN.md`(설계 원문)와 `docs/DECISIONS.md`(결정 기록 D1~D52)이다.

| 파일 | 내용 |
|---|---|
| `DESIGN_v1.0.md`, `DESIGN_v1.2.md` | 설계서 이전 판 |
| `DESIGN_filled.md` | 설계서 PDF 빌드 때 측정값을 채운 중간 산출물(`report/build_design_doc.py`) |
| `REVISION_v1.1.md`, `REVISION_v1.4.md` | 개정별 변경 사항과 처리 결과 |
| `HANDOFF_PROMPT.md` | 개발 단계 착수 시 작업 지시서(구현 범위·검증 체크리스트) |
